Two pilot plots, monitored end to end

A 2.5 ha paddy block in the Cauvery delta and a 2.9 ha shade-coffee block in the Kenyan highlands, run through the same quantification engine. Both are deliberately tiny, because the first thing a pilot has to answer is whether the arithmetic survives at plot scale.

What is real here, and what is not. The locations, climatology, crop calendars and methodology mechanics are real. The plot boundaries are drawn rather than surveyed, and every monitored value is simulated on the real 5-day Sentinel-2 revisit cadence — no satellite imagery was retrieved. The feed is deterministic and runs ahead of today, so each real revisit date that passes reveals a reading that was not visible before. Prices, costs and emission factors are placeholders.

What one plot is worth, and what it would take

Both plots run the same fixed machinery — validation, verification, registry fees, project operations. That cost does not care how much land sits inside the project, which is why plot-scale economics decide everything downstream.
